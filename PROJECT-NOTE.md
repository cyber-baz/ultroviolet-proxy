# Project note

This repository is a personal copy of the deployable [Ultraviolet-App](https://github.com/titaniumnetwork-dev/Ultraviolet-App) example from TitaniumNetwork.

Ultraviolet is an AGPL-3.0 web proxy implementation that uses service workers and BareMux transports. The upstream project is no longer actively maintained and recommends [Scramjet](https://github.com/MercuryWorkshop/scramjet) for new deployments. Review the upstream license, security posture, and applicable laws and policies before deploying.
